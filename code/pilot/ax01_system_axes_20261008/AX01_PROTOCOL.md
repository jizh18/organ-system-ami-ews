# AX01：知识系统轴检验（事前锁定，2026-10-08 约19:50）

## 问题

前几轮实验发现，跨指标组合有收益，但这些收益分散在大量指标对上。本实验检验：如果按病理生理知识把59个指标分成8个系统轴，能否把这些分散的信号收拢到少数“轴内组合 + 知识设定的轴间联动”里？以及收益是否来自这种特定的知识分组，而不是来自“任何分组都行”？

## 系统轴（见 axes.json）

8个轴：心肌损伤、泵功能/循环、灌注/酸碱、呼吸/氧合、肾/电解质、血液/凝血、炎症/体温、肝/代谢/其他。

按知识设定6组轴间联动：

| 轴间联动 | 对应的病理生理 |
|---|---|
| 损伤×循环 | 梗死→泵衰竭 |
| 循环×灌注 | 低灌注/休克（SCAI） |
| 灌注×呼吸 | 代谢性酸中毒的呼吸代偿／缺氧 |
| 循环×呼吸 | 心源性肺水肿（Killip） |
| 循环×肾 | 心肾综合征 |
| 灌注×肾 | 酸碱—肾—钾 |

## 比较臂

数据、内部5折、学习器和迭代数选择规则与KG01完全相同。

| 臂 | 允许的组合 |
|---|---|
| ADD | 只逐指标学习 |
| WITHIN | 只允许同一个轴内部的指标组合 |
| AXIS_KG | WITHIN，再加上6组知识设定的轴间联动 |
| AXIS_ALLPAIRS | WITHIN，再加上全部28组轴两两联动（参照） |
| FULL | 任意组合（上限参照） |
| RAND_r（19次） | 结构与AXIS_KG相同，但把指标随机分到各轴：按测量频率分6层，只在层内打乱，各轴大小不变；种子20261008 |

## 判定（写定，结果出来后不修改）

- **A1**：AXIS_KG补回FULL−ADD合并增益的比例，在NLL和AP上都≥60%。
- **A2**：在合并NLL上，AXIS_KG好于全部19个随机分组（置换p≤0.05）。
- **A3**：3个外折中，AXIS_KG的NLL和AP都优于ADD。

A1、A2、A3全部满足记为 **PASS**，否则记为未通过，如实记录，不改分组、不调参。
