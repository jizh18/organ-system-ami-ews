# EP2 评价协议（事前锁定，2026-10-09，在任何模型拟合之前）

## 终点

采用主定义，即非计划恶化：未来24小时内发生院内死亡、非计划的循环支持开始（升压药、正性肌力药、机械循环支持）或非计划的有创通气开始。心外围手术期与PCI围操作期的支持治疗不计入事件。预测时点为入院后6小时至14天，每6小时一个。共28216个时点、304个阳性时点、113名出事患者、1688名患者。

## 特征（主分析只用生理数值）

- **数值特征**：59个指标各取最近值、与上次相比的变化、相对本次入院首个值的变化、24小时最低值、24小时最高值。
- **派生量**：平均动脉压、休克指数、阴离子间隙、SpO2/FiO2，以及GCS总分。
- **尿量**：近6小时和近24小时的尿量（mL/kg/h）。
- **精选心电特征**：入院心电的ST抬高、前壁、宽QRS、房颤；最近一份心电的心率、QRS、QTc、房颤；ST回落；新发房颤。
- **基线信息**：年龄、性别、既往心衰/CKD/糖尿病/心梗（只用既往住院的诊断），以及入院后的小时数。
- **诊疗过程特征（只用于补充分析）**：测量次数、距上次测量的时间、估算的FiO2。

## 模型

所有模型使用同一个GBM：lr 0.05，最多500轮，训练集内部早停，8叶。评价采用按患者分组的5折交叉验证，重复3次（种子1000–1002），把折外预测取平均后计算指标。不读取旧项目的TEST划分；本研究的终点是新定义的，因此在全部1688名患者上做交叉验证。

| 模型 | 说明 |
|---|---|
| ADD | 逐指标学习，同一指标的各项特征可以组合 |
| AXIS（主模型） | 允许10个系统轴内部组合，再加8组知识设定的轴间联动：损伤×循环、循环×灌注、灌注×呼吸、循环×呼吸、循环×肾、灌注×肾、电学×循环、神经×灌注 |
| FULL | 不加约束的黑箱参照 |
| AXIS_noECG | AXIS去掉心电 |
| AXIS_old59 | AXIS只用原59个指标（无新派生量、尿量、GCS、心电、基线） |
| AXIS+PROC | AXIS加上诊疗过程轴（补充分析） |
| 临床评分 | NEWS2、休克指数、qSOFA，直接用作风险分数，不做拟合 |

## 指标（全部报告，不挑选）

- **区分度**：AP（同时给出阳性率和AP/阳性率的提升倍数）、AUROC。
- **报警表现**：在报警率为5%、10%、20%时，报告事件级灵敏度（出事前24小时内是否至少报警一次）、时点级灵敏度、PPV、NNE，以及被抓到的事件中最早一次报警比事件提前的小时数（中位数）。
- **校准**：Brier分数、校准斜率、整体校准偏差。
- **决策曲线**：阈值取2%、5%、10%时的净获益，并与“全部报警”比较。
- **成对比较**：用按患者的bootstrap（1000次）给出ΔAP和ΔAUROC的95%CI，比较以下各对：AXIS对NEWS2、AXIS对休克指数、FULL对AXIS、AXIS对AXIS_noECG、AXIS对AXIS_old59、AXIS对ADD、AXIS+PROC对AXIS。
- **分项结局**：AXIS对死亡、循环支持、呼吸支持三个分项分别报告AUROC。
